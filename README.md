# Inov@ nos Estudos

Site do centro de estudo em Gemunde (Maia, Portugal). Migrado do pacote de produção Design.com para React + Vite, sem alterações visuais.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19
- Vite
- Design system próprio (tokens + Button, Input, Select, RingFrame, PersonaCard)
